# Polpa Celulósica - BC-MW

Projeto de pesquisa: extração de celulose do bagaço de cana-de-açúcar (BC) por polpação organossolve — acetossolve, formossolve e organocat (MW) — e posterior branqueamento, para avaliar a qualidade do processo visando aplicações têxteis.

## Estrutura

- `Brutos/` — dados brutos (via OneDrive, fora do git)
- `dados/` — dados tratados e versionáveis
- `docs/` — textos, normas, referências
- `figuras/` — figuras geradas
- `relatorio/` — relatório em LaTeX (compilar com `pdflatex`, só o `.pdf` final vai ao git)

## Sincronizar neste e em outros PCs

```bash
git clone https://github.com/MatheusTeixeiraDias/polpa-celulosica-bc-mw.git
orca repo add --path "<caminho>/Polpa Celulósica - BC-MW"
```
